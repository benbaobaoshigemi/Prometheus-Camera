## 1. 已核对事实

### 1.1 CCM 分层

- 14U `cc13_bps_v2 / cc13_ife_v2` 只有单叶单位矩阵；18PM `cc132_ofe_v2` 关闭（单位矩阵）。两台机都只有 IPE 一块 CCM（14U CC14 / 18PM CC152），**标定与风格同在一块矩阵里**。
- 14U 主摄 DNG：`ColorMatrix1`（D65，Illuminant 21）与 `ColorMatrix2`（A，Illuminant 17）。按
  `CCM = XYZ→sRGB · Bradford(illum→D65) · CM⁻¹ · diag(neutral)`，行归一后：
  - D65 ↔ CC14 VIBR `awb1∈[1,64] / lux 140–370 / ≥4700K`，最大误差 0.0066；
  - A ↔ CC14 VIBR `awb1∈[1,64] / lux 140–230 / 2650–3350K`，最大误差 0.0061（不做色适应时误差 0.65，用 von Kries 时 0.25）。
  - 结论：tuning 内直接存放标定锚点，DNG 标定由它导出。
- 风格偏离定义：D(x) = CCM(x) · Cal(色温)⁻¹。18PM 锚点按同一规律定位：生动、awb1 第一档、lux≈230 档的 3000K 与 ≥4700K 矩阵。

### 1.2 相对标定的风格偏离（饱和度比 R/C、Y/B、G/M，日光，正常亮度）

| | awb1 低档 | awb1 高档 |
|---|---|---|
| 18PM 生动 主摄 | 1.00/1.00/1.00 | （无此档） |
| 18PM 生动 超广/长焦 | 1.00 | 0.74/0.97/0.86，色相 +4/+1/−11 |
| 18PM 原色 主摄/超广/长焦 | 1.00 / 0.95 / 0.91 | 0.89/0.74/0.74 …（同上一行的方向） |
| 14U 生动 主摄/超广 | awb1<1：**1.15–1.21 增艳**，绿/品色相最多 +18° | awb1≥1：1.00（即标定） |

- 暗光（lux 指数高）两种风格都收色 0.8–0.9，属于降噪适配。
- awb1 高档收色在 18PM 生动和原色上跨传感器一致，是小米通用机制，不是原色风格。
- 18PM 原色相对标定**无增艳**。

### 1.3 Gamma

- 14U VIBR 与 18PM 生动的 Gamma 包络一致（x=0.25：0.511–0.586 对 0.519–0.576；x=0.5：0.756–0.805 对 0.769–0.802）。
- 18PM 原色在 AINR/HDR/SE/SN/MMF/None 各主要路径上都是同一条固定曲线，相对生动为 −0.012/−0.07/−0.085/−0.044（x=0.125/0.25/0.5/0.75）；主摄与超广的曲线相同（与传感器无关）。

### 1.4 平台代际节点

14U VIBR LTM202 静态强度 0.2–1.65（已开启）；18PM 生动 `ltm_strength=0`，由 TMC 驱动；原色额外开启静态 LTM。属于平台差异，不迁移。

## 2. 组合公式

| 14U 节点 | 14U 原色 |
|---|---|
| CC14 | awb1≥1 档：保留 14U VIBR；awb1<1 档：替换为同一 (lux, cct) 的 awb1≥1 档矩阵（去增艳）。awb1≥2 收色待 awb1 同义性确认后再决定 |
| Gamma15（VIBR 全叶，R=G=B） | 18PM 原色固定曲线（257 点，10-bit） |
| LTM202 / TMC142 / GTM132 | 保留 14U VIBR |
| CV12 / TDL11 / CS20 / SCE11 | 保留 14U VIBR |
| Bayer 前端、3A、降噪、CC13 | 保留 14U |
