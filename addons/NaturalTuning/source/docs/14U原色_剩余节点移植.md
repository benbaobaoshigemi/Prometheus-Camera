# 18PM 原色相对生动的其余差异：逐项结论（V1.2.0）

范围：18PM 主摄（madrid_wide_a，普通拍照 Feature0=Natural(12) vs None(0)）。降噪类、天文/超级夜景不在范围内。

| 项 | 结论 | 做法 / 证据 |
|---|---|---|
| CV12 ↔ CV122（ap/am/cp/cm） | **已移植** | 14 浮点区域、触发轴 (drc, exp_sens, led_idx, lux, cct) 两侧完全相同；14U VIBR 与 18PM 生动同形（ap 0.54/0.53，其余 10 槽相同）。叶 = 14U 值 + (Natural−Vivid)，增量最大 0.055。`node_port.py` |
| TDL11 ↔ ColorLUT20（色相/饱和度 24×16 表） | **已移植** | TDL11 891 浮点 = 色相表 384 + 饱和度表 384 + 123 参数，对应 ColorLUT20 的一个平面（18PM 三个平面在每个叶里逐值相同，123 个参数与其边界常数一致）。叶 = 14U 表 + (Natural−Vivid)，增量最大约 8–10（单位同表）。 |
| LTM | **已移植**（V1.1.x） | 见 14U原色_LTM移植研究.md |
| TMC211 ↔ TMC142 | **无风格差异可移植** | 123 条路径中 90 条 Natural 与 Vivid 的叶数值完全相同（主路径只差触发区间边界）；33 条有差异的全部是 SuperDefinition / SuperDefinition_FLASH（生动有专属节点、原色回落通用节点的 B 类不对称），不是风格。 |
| GTM c1–c4（亮度权重） | **无差异** | LTM212 reserve 在 Natural 与 Vivid 之间只有 ltm_curve 不同，c1–c4 逐值相同；ltm_curve 14U 已是同值线性。 |
| 降噪、WB14、PDPC、CAC、ABF 等 B 类 | **不移植（按范围排除）** | 传感器适配节点 |
| AEC 天文/超级夜景分叉 | **不移植（按范围排除）** | |

## 上机（V1.2.0，热挂载）
- 安装通过，provider 稳定，两轮五档变焦（0.5/1x/2x/3.2x/5x）全部出图，无 tombstone。
- 同场景 A/B（1x，曝光一致）：V1.2.0 相对 V1.1.1 平均逐像素差 1.65，与重复性噪声 1.67 相同；有色像素饱和度比 ×1.014（红橙）/×0.986（青蓝），色相平均 +0.34°。CV12/TDL11 增量在该场景下低于噪声，与增量量级（≤约 1–2% 饱和度）相符。
